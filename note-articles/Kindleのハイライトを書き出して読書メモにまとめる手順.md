# Kindleのハイライトを書き出して読書メモにまとめる手順｜ブラウザで一覧を開いて、メモアプリへ移すまで

## 線を引いた箇所を、あとから見返せていない

Kindleで本を読むたびに、気になった文に線を引いています。ところが、読み終えたあとで見返すことはほとんどありません。会議の資料に1文引用したくても、どの本のどこだったか思い出せない。線を引いた箇所を、まとめて手元のメモに移す方法を探しています。

## 全体像：4ステップ、1冊あたり10分ほどで終わります

Kindleで引いた線の名前は「ハイライト」です。ハイライトは、端末の中だけでなく、Amazonのサーバーにも保存されています（Amazonで購入した本の場合）。そのため、パソコンのブラウザから一覧で開けるのです。

手順は4つです。

1. ハイライトの一覧をブラウザで開く（3分）
2. 1冊分のハイライトをコピーする（3分）
3. メモアプリに貼り付けて、読書メモの形に整える（5分）
4. 次の本から、読みながら書き出しやすくしておく（初回だけ5分）

スマホのKindleアプリから、メールでまとめて送る方法もあります。こちらはステップ2の後半が該当箇所です。

### 始める前に手元に置くもの

- Kindleで本を買ったAmazonのアカウント（メールアドレスとパスワード）
- パソコン（ブラウザで一覧を開いてコピーします）
- 普段使っているメモアプリ（Notion、Evernote、Googleドキュメント、iPhoneのメモなど）
- ハイライトを付けたことのある本を1冊

### この記事で片付くこと

読み終えたときには、次の状態になっています。

- ハイライトの一覧を、いつでもブラウザで開ける
- 1冊分のハイライトが、メモアプリの読書メモにまとまっている
- 次に読む本から、読みながらメモを残す習慣の準備ができている

有料の外部ツールや、プログラムを使った自動化は扱いません。無料でそろう道具だけで、今日のうちに1冊分を片付けるための記事です。

## ステップ1：ハイライトの一覧をブラウザで開く

パソコンを使います。スマホのブラウザでも開けますが、コピーする範囲を選ぶ操作がしにくいためです。

1. ブラウザで「read.amazon.co.jp/notebook」を開きます。Kindleの「メモとハイライト」というページです
2. Amazonのアカウントでログインします。Kindleで本を買ったときと同じアカウントを使います
3. 画面の左側に、ハイライトがある本の一覧が表示されます
4. 書き出したい本のタイトルをクリックします
5. 画面の右側に、その本のハイライトが、本の中の順番どおりに並びます

左側の一覧に本が出てこない場合は、「つまずきやすい箇所」の項目を見てください。

## ステップ2：1冊分のハイライトをコピーする

### パソコンのブラウザでコピーする方法

1. 右側のいちばん上のハイライトの、文の先頭をクリックします
2. そのまま下までスクロールし、Shiftキーを押しながら、最後のハイライトの文末をクリックします
3. Windowsなら「Ctrl」＋「C」、Macなら「command」＋「C」でコピーします

これで、ハイライトの本文と「位置No.」（本の中の場所を示す番号）がまとめてコピーされます。

### スマホのKindleアプリからメールで送る方法

1. Kindleアプリで、書き出したい本を開きます
2. 画面の中央をタップして、メニューを表示します
3. 上部のノートのアイコンをタップし、メモとハイライトの一覧を開きます（※注：アイコンの形と名前はアプリのバージョンで変わります。見つからない場合は、ライブラリ画面の「マイノート」から本を選んでも同じ一覧が開きます）
4. 共有（エクスポート）のアイコンをタップし、書き出しを選びます（※注：メニューの文言はアプリのバージョンで変わることがあります）
5. 形式は「なし」、送信方法はメールを選び、自分宛てに送ります

届いたメールに、HTMLファイルが添付されています。開くと、ハイライトの一覧が表示されるはずです。

**出版社が書き出しの量を制限している本もあります。** その場合、エクスポートやコピーは途中で切れてしまうので注意してください。上限は出版社が本ごとに決めていて、全体の10%程度しか書き出せない本もあります。

## ステップ3：メモアプリに貼り付けて、読書メモの形に整える

使うメモアプリは、普段使っているもので構いません。Notion、Evernote、Googleドキュメント、iPhoneのメモなど、どれでも手順は同じです。

1. 新しいメモを作り、タイトルに「書名／著者名」を入れます
2. ステップ2でコピーした内容を貼り付けます
3. 貼り付けた内容の上に、次の書式を足します

```
# 書名／著者名
読了日：2026年〇月〇日

## この本から持ち帰る1文
（ハイライトの中から1つだけ選んで貼る）

## 仕事で使えそうなところ
・（ハイライトを1つ貼る）→ どう使うか1行
・（ハイライトを1つ貼る）→ どう使うか1行

## ハイライト全文
（ステップ2で貼り付けた内容）
```

「持ち帰る1文」と「仕事で使えそうなところ」は、全部埋めなくて構いません。空欄があっても、全文が残っていれば後で探せます。

### 引用するときのために、位置No.を残す

ハイライトの横にある位置No.は、消さずに残してください。会議の資料に引用するとき、Kindleアプリの「移動」→「位置No.」から、元の場所へすぐ戻れます（※注：メニューの名前はアプリのバージョンで変わることがあります）。

## ステップ4：次の本から書き出しやすくしておく

読みながら、ハイライトに短いメモを付けておくと、ステップ3の「どう使うか」がそのまま埋まります。

1. Kindleアプリで文を長押しし、ハイライトを付けます
2. 表示されたメニューから「メモ」を選びます（※注：端末やアプリのバージョンによって、ボタンの表記が違うことがあります）
3. 「会議で使う」「〇〇案件」など、10文字程度の一言を入れます

メモを付けたハイライトは、ステップ1の一覧でも、ハイライトの下に表示される仕組みです。

## つまずきやすい箇所と対処

**ブラウザの一覧に、本が出てこない**
次の3つを順に確かめます。

1. Kindleで本を買ったときと同じAmazonアカウントでログインしているか
2. 本を読んだ端末が、インターネットにつながった状態で同期されたか。Kindleアプリで「同期」を実行します（※注：同期のボタンの場所はアプリのバージョンで変わります。多くはライブラリ画面かメニューの中にあります）
3. 自分で転送したPDFや文書（パーソナルドキュメント）ではないか。これらのハイライトは一覧に出ないことがあります（※注：パーソナルドキュメントの扱いは、ネット上でも情報が分かれていて、はっきりしませんでした。出ない場合は、Kindleアプリのエクスポートを試してください）

**コピーしたら、余計な文字まで入った**
「黄色のハイライト」「位置No.」といった表示も一緒にコピーされます。気になる場合は、メモアプリの検索と置換で「黄色のハイライト」を空欄に置き換えます。

**エクスポートのメールが届かない**
Kindleアプリに登録しているメールアプリが、送信先として選ばれているかを確かめます。迷惑メールフォルダも見てください。

**何冊も溜まっていて、どこから手を付けるか決められない**
全部を一度に移す必要はありません。まず、この1か月で読んだ本を1冊だけ選びます。次に、仕事で引用したくなりそうな本を1冊。この2冊が終われば、残りは週に1冊ずつで十分です。

**紙の本のメモも、同じ場所にまとめたい**
紙の本は、ステップ3の書式をそのまま使い、「ハイライト全文」の欄に手で打ち込みます。ページ番号を位置No.の代わりに書いておけば、Kindleの本と同じ形で探せます。

**ハイライトが途中で切れている**
ステップ2の最後に書いた、出版社の制限の可能性があります。切れた部分は、本を開いて手で書き写すしかありません。

## 終わったかどうかの確認

次の3つがそろえば完了です。

- メモアプリに、書名つきの読書メモが1つできている
- メモの中に、ハイライトの全文と位置No.が入っている
- 「この本から持ち帰る1文」に、少なくとも1文が入っている

試しに、メモアプリの検索欄に本文中の単語を1つ入れてみてください。そのメモが検索結果に出れば、次からは本を開かなくても探せます。
