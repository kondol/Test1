# Visit Japan Webで帰国時の税関申告を済ませる手順｜日本人の帰国に必要な部分だけ

## 帰国便の中で、紙とアプリのどちらを使うか迷っている

海外からの帰国便の中です。客室乗務員から紙の税関申告書を配られました。一方で、「Visit Japan Webを使えば早い」とも聞きます。どちらを使えばいいのか。アプリの登録画面を開いてみたら項目が多く、どこまで入力すればいいのか分からず止まっています。

## 全体像：日本人の帰国なら、5ステップで終わります

Visit Japan Web（ビジット・ジャパン・ウェブ）は、入国の手続きをスマホで済ませるための、国のWebサービスです。アプリではなく、ブラウザで開くWebページとして提供されています【要確認】。

日本のパスポートで帰国する人に必要なのは、主に「税関申告」の部分です。入国審査は、空港の顔認証ゲートで済ませられます【要確認：利用できる空港とゲートの条件】。

手順は、次の5つです。

1. アカウントを作る（5分）
2. 本人情報を登録する（5分）
3. 帰国の予定を登録する（3分）
4. 税関申告の内容を入力する（5分）
5. QRコードを表示して空港で使う

1から3は、**出発前に日本で済ませておけます。** 機内や到着後に慌てずに済むので、先に片付けておくのがおすすめです。

### 始める前に手元に置くもの

- パスポート（顔写真のページを読み取ります）
- スマホ（カメラとブラウザを使います）
- 帰国便の搭乗券か、eチケットの控え（便名と到着日を確かめます）
- 海外で買った物のレシート（税関申告の質問に答えるときに使います）

### この記事で片付くこと

読み終えたときには、次の状態になっています。

- Visit Japan Webのアカウントと本人情報の登録が済んでいる
- 今回の帰国予定と、税関申告の内容が登録されている
- 空港で見せるQRコードが、スマホに保存されている

外国籍の家族の入国審査や、検疫の手続きは、この記事では扱いません【要確認：対象者によって必要な手続きが変わる】。日本のパスポートで帰国する人が、税関を早く抜けるための記事です。

## ステップ1：アカウントを作る

1. ブラウザで「Visit Japan Web」と検索し、デジタル庁の公式ページを開きます【要確認：公式URL】
2. 「新規アカウント作成」をタップします
3. メールアドレスとパスワードを入力し、利用規約に同意します
4. 届いた確認メールに書かれた「確認コード」を入力します

確認メールが届かない場合は、迷惑メールフォルダを確かめてください。

## ステップ2：本人情報を登録する

1. ログイン後のトップ画面で「本人情報の登録」をタップします【要確認：画面の表記】
2. 「パスポートを読み取る」を選び、パスポートの顔写真のページをカメラで撮影します
3. 読み取られた氏名、生年月日、パスポート番号、有効期限を目で確かめます
4. 「日本国籍」かどうかの質問に「はい」を選びます【要確認】
5. 日本の住所など、残りの項目を入力して保存します

カメラでうまく読めない場合は、「手入力」に切り替えて、パスポートを見ながら打ち込みます。

## ステップ3：帰国の予定を登録する

1. トップ画面の「新規登録（入国・帰国予定）」をタップします【要確認】
2. 「日本への到着予定日」を入力します。**日本時間の日付**です
3. 利用する航空会社と便名を入力します。便名は、搭乗券やeチケットに書かれた「NH〇〇〇」「JL〇〇〇」などの英数字です
4. 滞在先の欄は、日本の自宅住所を選ぶか入力します
5. 保存します

同じ人が年に何度も海外へ行く場合、帰国のたびにこのステップ3だけを追加します。アカウントと本人情報は使い回せるので、登録し直す必要はありません。

## ステップ4：税関申告の内容を入力する

1. ステップ3で登録した予定を開きます
2. 「携帯品・別送品申告」をタップします【要確認：画面の表記】
3. 質問に順番に答えます。主な質問は次のとおりです
   - 日本への持ち込みが禁止・制限されているものを持っているか
   - 免税範囲を超える買い物をしたか
   - 100万円相当を超える現金などを持っているか【要確認：金額の基準】
   - 別送品（自分とは別に送った荷物）があるか
4. 答えを見直して、「登録」をタップします

### 買い物が免税範囲を超えているか分からないとき

免税範囲は、お酒・たばこ・香水・その他の品物で基準が分かれています【要確認：最新の数量と金額は税関の公式ページで確認】。レシートを並べて、品目ごとに合計を出してから答えてください。迷う場合は「超えている」側で申告し、空港の税関職員に確認してもらう方が安全です。

## ステップ5：QRコードを表示して空港で使う

1. 税関申告の登録が終わると、「QRコードを表示」のボタンが出ます
2. 日本の空港に着いて荷物を受け取ったら、税関の「電子申告端末」へ進みます【要確認：空港ごとの設置状況】
3. 端末にQRコードとパスポートをかざし、顔写真の撮影に応じます
4. 端末の案内に従って、「電子申告ゲート」を通ります【要確認】

機内や空港ではWi-Fiが不安定なことがあります。**QRコードが表示されたら、スクリーンショットを撮っておいてください。**

## つまずきやすい箇所と対処

**家族と一緒に帰国する**
同伴する家族（配偶者や子どもなど）は、「同伴家族」として同じアカウントに登録できます【要確認】。ステップ2のあとで「同伴家族の登録」から追加します。税関申告を家族分まとめて行えるかは、画面の案内で確かめてください【要確認】。

**到着日を現地時間で入れてしまった**
夜の便や長距離便では、現地の日付と日本の日付がずれます。登録した予定を開き、到着予定日を日本時間に直してから保存します。

**便名を入れたら候補に出てこない**
共同運航便（複数の航空会社が同じ便を運航するもの）では、運航している側の便名で登録すると通ることがあります【要確認】。eチケットの「運航会社」の欄を見てください。

**ログインできない、パスワードを忘れた**
ログイン画面の「パスワードを忘れた方」から、登録したメールアドレスで再設定します【要確認：画面の表記】。登録したアドレス自体が分からない場合は、普段使っているアドレスを順に試してください。新しいアカウントを作り直すこともできますが、本人情報の登録からやり直しになります。

**次の旅行でも使いたい**
アカウントと本人情報は、そのまま残ります。パスポートを更新した場合だけ、本人情報のパスポート番号と有効期限を直してください【要確認】。古い番号のままだと、空港の端末で読み取りが通らないことがあります。

**空港でスマホの電池が切れた、QRコードが開けない**
機内で配られる紙の申告書に書き、通常の税関検査台へ進めば手続きできます【要確認：紙の運用が続いているか】。電池切れに備えて、到着前にスクリーンショットを撮り、モバイルバッテリーを手荷物に入れておくと安心です。電子申告ゲートが混んでいる時間帯もあるので、紙に切り替える判断は早めで構いません。

**同じ便の同行者が、自分のスマホで別に登録したい**
同行者が自分のアカウントを持っている場合は、それぞれで税関申告を登録しても問題ありません【要確認】。その場合、空港の端末も1人ずつ通ります。家族でまとめたいか、別々に通りたいかを、出発前に決めておいてください。

**紙の申告書を書いてしまった**
紙の申告書でも手続きはできます【要確認：紙の運用が続いているか】。Visit Japan Webと紙の両方を出す必要はありません。

## 終わったかどうかの確認

次の3つがそろえば準備完了です。

- トップ画面の帰国予定に、「税関申告：登録済み」のような表示が出ている【要確認：画面の表記】
- QRコードが表示でき、スクリーンショットがカメラロールに保存されている
- パスポートをすぐ出せる場所に入れてある

空港では、税関の電子申告ゲートを通過できれば手続きは終わりです。
