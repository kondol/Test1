# Visit Japan Webで帰国時の税関申告を済ませる手順｜日本人の帰国に必要な部分だけ

## 帰国便の中で、紙とアプリのどちらを使うか迷っている

海外からの帰国便の中です。客室乗務員から紙の税関申告書を配られました。一方で、「Visit Japan Webを使えば早い」とも聞きます。どちらを使えばいいのか。アプリの登録画面を開いてみたら項目が多く、どこまで入力すればいいのか分からず止まっています。

## 全体像：日本人の帰国なら、5ステップで終わります

Visit Japan Web（ビジット・ジャパン・ウェブ）は、入国の手続きをスマホで済ませるための、国のWebサービスです。アプリではなく、ブラウザで開くWebページとして提供されています。

日本のパスポートで帰国する人に必要なのは、主に「税関申告」の部分です。日本国籍の人は、入国審査の登録（外国人入国記録）が要りません。入国審査は、パスポートの確認か、主要空港にある顔認証ゲートで受けます。

手順は、次の5つです。

1. アカウントを作る（5分）
2. 利用者情報を登録する（5分）
3. 帰国の予定を登録する（3分）
4. 税関申告の内容を入力する（5分）
5. QRコードを表示して空港で使う

1から3は、**出発前に日本で済ませておけます。** 機内や到着後に慌てずに済むので、先に片付けておくのがおすすめです。

### 始める前に手元に置くもの

- パスポート（顔写真のページを読み取ります）
- スマホ（カメラとブラウザを使います）
- 帰国便の搭乗券か、eチケットの控え（便名と到着日を確かめます）
- 海外で買った物のレシート（税関申告の質問に答えるときに使います）

### この記事で片付くこと

読み終えたときには、次の状態になっています。

- Visit Japan Webのアカウントと利用者情報の登録が済んでいる
- 今回の帰国予定と、税関申告の内容が登録されている
- 空港で見せるQRコードが、スマホに保存されている

外国籍の家族の入国審査や、検疫の手続きは、この記事では扱いません。日本のパスポートで帰国する人が、税関を早く抜けるための記事です。

## ステップ1：アカウントを作る

1. ブラウザで「Visit Japan Web」と検索し、デジタル庁の公式ページ（www.vjw.digital.go.jp）を開きます
2. 「新規アカウント作成」をタップします
3. メールアドレスとパスワードを入力し、利用規約に同意します
4. 届いた確認メールに書かれた「確認コード」を入力します

確認メールが届かない場合は、迷惑メールフォルダを確かめてください。

## ステップ2：利用者情報を登録する

1. ログイン後のトップ画面で「利用者情報の登録」をタップします
2. 「パスポートを読み取る」を選び、パスポートの顔写真のページをカメラで撮影します
3. 読み取られた氏名、生年月日、パスポート番号、有効期限を目で確かめます
4. 国籍の欄で「日本」を選びます（※注：国籍を尋ねる欄の文言は、画面の更新で変わることがあります）
5. 日本の住所など、残りの項目を入力して保存します

カメラでうまく読めない場合は、「手入力」に切り替えて、パスポートを見ながら打ち込みます。

## ステップ3：帰国の予定を登録する

1. トップ画面の「入国・帰国の予定を新規登録する」をタップします（※注：ボタンの文言は、画面の更新で多少変わることがあります）
2. 「日本への到着予定日」を入力します。**日本時間の日付**です
3. 利用する航空会社と便名を入力します。便名は、搭乗券やeチケットに書かれた「NH〇〇〇」「JL〇〇〇」などの英数字です
4. 滞在先の欄は、日本の自宅住所を選ぶか入力します
5. 保存します

同じ人が年に何度も海外へ行く場合、帰国のたびにこのステップ3だけを追加します。アカウントと利用者情報は使い回せるので、登録し直す必要はありません。

## ステップ4：税関申告の内容を入力する

1. ステップ3で登録した予定を開きます
2. 「携帯品・別送品申告」をタップします
3. 質問に順番に答えます。主な質問は次のとおりです
   - 日本への持ち込みが禁止・制限されているものを持っているか
   - 免税範囲を超える買い物をしたか
   - 100万円相当額を超える現金・小切手などを持っているか
   - 別送品（自分とは別に送った荷物）があるか
4. 答えを見直して、「登録」をタップします

### 買い物が免税範囲を超えているか分からないとき

免税範囲は、品目ごとに次のように決まっています。

- お酒：3本（1本760ml程度のもの）
- たばこ：紙巻たばこなら200本
- 香水：2オンス（約56ml。オーデコロンやオードトワレは含みません）
- その他の品物：海外での購入価格の合計が20万円まで（1品目ごとの合計が1万円以下のものは、原則として数えません）

（※注：2026年9月時点で確認した内容です。改定されることがあるため、出発前に税関の「海外旅行者の免税範囲」のページで最新の数量と金額を確かめてください）

レシートを並べて、品目ごとに合計を出してから答えてください。迷う場合は「超えている」側で申告し、空港の税関職員に確認してもらう方が安全です。

## ステップ5：QRコードを表示して空港で使う

1. 税関申告の登録が終わると、「QRコードを表示」のボタンが出ます
2. 日本の空港に着いて荷物を受け取ったら、税関の「電子申告端末」へ進みます。電子申告ゲートがあるのは、新千歳・成田・羽田・中部・関西・福岡・那覇の7空港です。ほかの空港でも、税関検査台の読み取り端末でQRコードを使えます
3. 端末にQRコードとパスポートをかざし、顔写真の撮影に応じます
4. 端末の案内に従って、「電子申告ゲート」を通ります

機内や空港ではWi-Fiが不安定なことがあります。**QRコードが表示されたら、スクリーンショットを撮っておいてください。**

## つまずきやすい箇所と対処

**家族と一緒に帰国する**
子どもなど、自分で手続きしにくい家族は、「同伴家族」として代表者のアカウントに最大10人まで登録できます。追加する場所は、ステップ2のあとの同伴家族の登録画面です。税関申告では、同伴家族の分もまとめて申告するかを選ぶ項目があり、「はい」にすると家族分の入力を一部省けます。ただし、空港の端末ではQRコードを1人ずつ読み取るのが基本です。画面のプルダウンで、家族ごとのQRコードに切り替えて見せます。

**到着日を現地時間で入れてしまった**
夜の便や長距離便では、現地の日付と日本の日付がずれます。登録した予定を開き、到着予定日を日本時間に直してから保存します。

**便名を入れたら候補に出てこない**
共同運航便（複数の航空会社が同じ便を運航するもの）では、実際に運航している航空会社の便名で登録します。eチケットの「運航会社」の欄を見てください。

**ログインできない、パスワードを忘れた**
ログイン画面のパスワード再設定のリンクから、登録したメールアドレスで再設定します（※注：リンクの文言は、画面の更新で変わることがあります）。登録したアドレス自体が分からない場合は、普段使っているアドレスを順に試してください。新しいアカウントを作り直すこともできますが、利用者情報の登録からやり直しになります。

**次の旅行でも使いたい**
アカウントと利用者情報は、そのまま残ります。パスポートを更新した場合だけ、利用者情報のパスポート番号と有効期限を登録し直してください。古い番号のままだと、空港の端末で読み取りが通らないことがあります。

**空港でスマホの電池が切れた、QRコードが開けない**
機内で配られる紙の申告書に書き、通常の税関検査台へ進めば手続きできます。紙の申告書は、機内のほか、空港の税関検査場にも置かれています。電池切れに備えて、到着前にスクリーンショットを撮り、モバイルバッテリーを手荷物に入れておくと安心です。電子申告ゲートが混んでいる時間帯もあるので、紙に切り替える判断は早めで構いません。

**同じ便の同行者が、自分のスマホで別に登録したい**
同行者が自分のアカウントを持っている場合は、それぞれのアカウントで税関申告を登録できます。その場合、空港の端末も1人ずつ通ります。家族でまとめたいか、別々に通りたいかを、出発前に決めておいてください。

**紙の申告書を書いてしまった**
紙の申告書でも手続きはできます。Visit Japan Webと紙の両方を出す必要はありません。

## 終わったかどうかの確認

次の3つがそろえば準備完了です。

- トップ画面の帰国予定に、税関申告が登録済みであることを示す表示が出ている（※注：表示の文言は、画面の更新で変わることがあります）
- QRコードが表示でき、スクリーンショットがカメラロールに保存されている
- パスポートをすぐ出せる場所に入れてある

空港では、税関の電子申告ゲートを通過できれば手続きは終わりです。
