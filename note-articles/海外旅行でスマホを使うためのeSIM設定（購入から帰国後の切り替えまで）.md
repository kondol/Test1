# 海外旅行でスマホを使うためのeSIM設定｜購入から、帰国後に元へ戻すまで

## eSIMを買ったのに、どこを押せばいいか分からない

明日から海外です。現地でスマホを使うためにeSIMを買いました。届いたメールにはQRコードが1つあるだけで、次に何をすればいいのか書いていません。回線が2つになったら、日本の番号はどうなるのか。高額な請求が来ないかも気になり、手が止まっています。

## 全体像：5ステップ。出発前に3つ、現地で1つ、帰国後に1つ

eSIMとは、スマホに内蔵されたSIMのことです。カードを差し替える代わりに、データを読み込んで回線を追加します。

手順は5つです。出発前の3つは、自宅のWi-Fiにつないだ状態で済ませます。

1. 【出発前】スマホがeSIMを使えるか確かめる（5分）
2. 【出発前】eSIMを購入する（10分）
3. 【出発前】eSIMをスマホに読み込む（10分）
4. 【現地】回線を切り替える（3分）
5. 【帰国後】日本の回線に戻す（3分）

いちばん気をつけたいのは、4の「どちらの回線でデータ通信するか」の設定です。ここを間違えると、日本の回線で海外ローミング（海外で日本の回線をそのまま使うこと）の料金が発生します。

### 始める前に手元に置くもの

- 旅行に持っていくスマホ本体
- 自宅のWi-Fi（読み込みに通信が必要なため）
- QRコードを表示するための、もう1台の画面（パソコンや家族のスマホ）
- 旅程表（行く国と、出発日・帰国日が分かるもの）

### この記事で片付くこと

読み終えたときには、次の状態になっています。

- 自分のスマホでeSIMが使えるかどうかが分かっている
- 旅行用の回線がスマホに入り、出発を待つだけになっている
- 現地に着いてから押す場所と、帰国後に戻す場所が分かっている

ポケットWi-Fiのレンタルや、携帯電話会社の海外定額プランとの比較はしません。eSIMで行くと決めた人が、設定を終わらせるための記事です。画面の名前は、AppleとGoogleの公式ヘルプを2026年9月時点で確かめています。変わりやすい箇所には注釈を付けました。

## ステップ1：スマホがeSIMとSIMロック解除に対応しているか確かめる

### iPhoneの場合

1. 「設定」→「一般」→「情報」の順に開きます
2. 下へスクロールし、「EID」という32桁の番号が表示されているか見ます
3. 同じ画面の「SIMロック」が「SIMロックなし」になっているか見ます

EIDがあればeSIMに対応しています。目安として、iPhone XS・XR以降と、iPhone SE（第2世代）以降が対応機種です。「SIMロックなし」でなければ、購入元の携帯電話会社でロック解除の手続きが必要です。

### Androidの場合

「設定」→「デバイス情報」→「SIMのステータス」の順に開き、「EID」の項目を探します（※注：メニューの名前は機種ごとに少し違います。「端末情報」となっている機種もあります）。見つからない場合は、機種名と「eSIM 対応」で調べてください。

## ステップ2：eSIMを購入する

eSIM販売サイトやアプリで、次の3点を決めて購入します。

- **国・地域**：周遊する場合は、複数の国に対応したプランを選びます
- **日数**：出発日から帰国日までを数えます。現地で初めて回線につながった時点から、24時間ごとに1日と数えるプランが多くあります（※注：日数の数え方はプランごとに違うため、購入画面の説明を確かめてください）
- **データ量**：地図とメッセージ中心なら少なめ、動画を見るなら多めにします

購入後、メールかアプリに次の2つが届きます。

- QRコード
- 手動入力用の情報（「SM-DP+アドレス」と「アクティベーションコード」という2つの文字列）

## ステップ3：eSIMをスマホに読み込む

**自宅のWi-Fiにつないでから始めてください。** 読み込みには通信が必要です。

### iPhoneの場合

1. 「設定」→「モバイル通信」を開きます
2. 「eSIMを追加」をタップします（※注：iOSのバージョンによっては「モバイル通信プランを追加」と表示されます）
3. 「QRコードを使用」を選び、別の画面に表示したQRコードを読み取ります
4. 回線の名前を聞かれたら「旅行」など分かりやすい名前を付けます。元の回線は「主回線」のままにします
5. 「デフォルト回線」の選択画面では、いったん「主回線」を選びます
6. 「モバイルデータ通信」の選択画面でも、いったん「主回線」を選びます

5と6で旅行用を選ぶと、プランによっては、日本にいる間に利用日数のカウントが始まってしまうことがあります（※注：多くの旅行用eSIMは、現地の電波に初めてつながった時点で有効期間が始まりますが、インストールした時点で始まるプランもあります。購入画面の説明を確かめてください）。

### Androidの場合

1. 「設定」→「ネットワークとインターネット」→「SIM」を開きます（※注：Google Pixelの表記です。ほかのメーカーの機種では、メニューの名前が違うことがあります）
2. 「SIMを追加」→「eSIMを設定」の順にタップします
3. QRコードを読み取り、ダウンロードが終わるのを待ちます
4. 追加された旅行用の回線は、いったんオフにしておきます

### QRコードが読み取れないときは手動で入力する

QRコードを読み取る画面の下に、「詳細情報を手動で入力」というリンクがあります（Androidでは「ヘルプが必要な場合」などから手動入力に進みます。※注：Androidの表記は機種ごとに違います）。ここに、メールに書かれたSM-DP+アドレスとアクティベーションコードを貼り付けてください。

## ステップ4：現地に着いたら回線を切り替える

飛行機を降りたら、次の順番で設定します。

### iPhoneの場合

1. 「設定」→「モバイル通信」を開きます
2. 「モバイルデータ通信」をタップし、旅行用の回線を選びます
3. 同じ画面の「モバイルデータ通信の切り替えを許可」をオフにします
4. 回線一覧から旅行用の回線を開き、「データローミング」をオンにします
5. 回線一覧から主回線を開き、「データローミング」がオフになっていることを確かめます

4で旅行用の回線のデータローミングをオンにするのは、旅行用eSIMは、現地の携帯電話会社の回線に「ローミング」でつながる仕組みのものが多く、オフのままだと通信できないためです。旅行用eSIMは前払いの定額制が主流なので、オンにしても購入した金額を超える請求は来ません（※注：一部に例外のプランもあるため、購入画面の説明も確かめてください）。

### Androidの場合

1. 「設定」→「ネットワークとインターネット」→「SIM」を開きます
2. 旅行用の回線を開き、「SIMを使用」と「ローミング」をオンにします
3. 「モバイルデータ」の優先回線を、旅行用の回線にします
4. 主回線を開き、「ローミング」がオフになっていることを確かめます

画面上部のアンテナ表示の横に、「4G」「5G」「LTE」などが出れば通信できています。

## つまずきやすい箇所と対処

**QRコードを、そのスマホ自身の画面で読み取れない**
自分の画面は、自分のカメラでは読み取れません。パソコンや家族のスマホに表示するか、ステップ3の手動入力を使ってください。

**現地に着いても「圏外」のまま**
次の順番で確かめます。

1. 旅行用の回線のデータローミングがオンになっているか
2. 「モバイルデータ通信」が旅行用の回線になっているか
3. スマホを再起動したか
4. 購入したプランの案内に「APN設定」（接続先の設定）の指定があるか。指定があるプランでは、案内どおりに手で入力します

**日本の番号への電話やSMSはどうなるのか**
主回線は、音声通話とSMSの回線として残ります。SMSの受信は、ドコモ・au・ソフトバンクとも無料です。一方、海外で電話を受けると、着信側にも通話料がかかります（※注：料金は契約中の携帯電話会社とプランによって違います）。不安な場合は、主回線そのものをオフにしておくと安心です。

**データの残量が分からない**
残量は、eSIMを買ったサイトやアプリのマイページで見られることが多いです（※注：確認方法は販売元ごとに違います）。iPhoneなら「設定」→「モバイル通信」の下にある、回線ごとの使用量も目安になります。ただしこの数字は、eSIMを入れてからの合計です。プランの残量とは一致しないことがあります。

**2か国を回る途中で、つながらなくなった**
国境を越えた直後は、現地の電波をつかむまで数分かかることがあります。機内モードを一度オンにし、10秒ほど待ってからオフに戻します。それでもつながらない場合は、購入したプランがその国に対応しているかを、プランの案内で見直してください。

**eSIMを間違えて削除してしまった**
一度削除したeSIMは、同じQRコードで入れ直せないことが多く、買い直しになります。インストール用のQRコードは、1回しか使えないものが主流です。削除する前に、ステップ5の判断基準を読んでください。

## ステップ5：帰国後、日本の回線に戻す

日本に着いたら、ステップ4を逆の順番で戻します。

1. 「モバイルデータ通信」を主回線に戻します
2. 旅行用の回線をオフにします（iPhoneは「設定」→「モバイル通信」で旅行用の回線を開き、「この回線をオンにする」をオフにします）
3. 主回線でWebページが開けるか確かめます

旅行用のeSIMは、すぐに削除しなくてもかまいません。次の旅行でも同じ販売元でチャージ（追加購入）して使える場合があります（※注：チャージに対応しているかは販売元ごとに違います）。使い切りのプランなら、有効期限が過ぎてから削除すると安全です。

## 終わったかどうかの確認

次の4つを確認できれば完了です。

- 現地で、Wi-Fiを切った状態で地図アプリが動いた
- 現地で、主回線のデータローミングがオフのままだった
- 帰国後、主回線でWebページが開けた
- 翌月の携帯電話料金に、海外ローミングの請求が載っていない

最後の項目は翌月にしか分かりません。明細が出る日をカレンダーに入れておいてください。
